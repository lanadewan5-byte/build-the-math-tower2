# BUILD THE MATH TOWER — ابنِ برج العمليات

لعبة تعليمية ثلاثية الأبعاد لطلاب الصف الرابع لتدريبهم على ترتيب خطوات حل مسائل أولويات العمليات.

## التشغيل
- افتح `index.html` عبر خادم محلي أو GitHub Pages.
- التحكم: الأسهم أو WASD للحركة، وSpace للقفز، وE لفتح محطة البناء عند الاقتراب منها.
- اسحب البطاقات إلى أماكنها أو انقر البطاقة ثم مكانها.

## النشر
يتم نشر الموقع تلقائيًا إلى GitHub Pages عند الدفع إلى فرع `main` عبر GitHub Actions.

المشروع مستقل تمامًا عن مستودع `math-obby`.
